## §17.1 defects assigned to M2

- **#1 Empty Semgrep results become `semgrep.ok`, ignoring the exit code.** Not met. `findings._semgrep_rows` does this, and `tests/test_findings.py` `test_semgrep_empty_results_emit_ok` asserts it.
- **#2 A missing Semgrep, a timeout, or empty stdout raises.** Partial. `tests/test_skeleton.py` `test_stage_exception_is_block_not_finished` turns a raised `semgrep.scan` into BLOCK `not_finished`, so the CLI does not print a traceback. The stage does not return `semgrep_unavailable`, `semgrep_timeout`, or `semgrep_failed`. No test injects a missing binary, a hang, or empty stdout.
- **#3 Only `SKILL.md` is checked for being skipped.** Not met. `findings._first_skill_md` looks only for that name. `test_skill_md_skipped` asserts `skill_md_skipped`. There is no `target_not_scanned` and no liveness canary.
- **#4 No Unicode normalization.** Not met. Nothing strips `Cf` or records `obfuscation.unicode` from a file. The policy can ASK on that finding if a caller supplies one (`test_decide` id `obfuscation_unicode`). Intake never supplies it.
- **#5 Folded-scalar memory regex.** Not met. `src/skill_warden/rules/memory.yaml` still uses `pattern-regex: >-`. There are no `dotslash-memory` or `zero-width-memory` fixtures.
- **#6 The reader body reads every file as UTF-8.** Not met. `pipeline._reader_body` calls `Path.read_text(encoding="utf-8")`. A binary would raise, and the pipeline catch would report BLOCK `not_finished`. There is no text or binary classification and no PNG fixture test.
- **#7 No cap on reader input.** Not met. The joined skill text is sent as-is. `max_input_chars` does not exist. The reader cap is also M4-01; the M2 acceptance list still includes this defect, and it is open.
- **#8 `content_hash` raises on any symlink.** Partial. v1 and v2 both raise `SkillTreeError` (`test_symlink_raises`, `test_v2_symlink_raises`). The pipeline catch makes that BLOCK `not_finished`. There is no intake `symlink` finding. The policy case `symlink` passes only when the finding is handed to `decide` directly.
- **#10 Docker files are found with `parents[2]`.** Not met. `jail.py` and `sink.py` set `_REPO_ROOT` from `Path(__file__).resolve().parents[2]`. No test shows that lookup failing from a wheel. Wheel detonation is M6.
- **#13 Two pipelines.** Not met. `orchestrator.py` still writes through `store.py`, and `jail.detonate` still runs for the CLI through `MemoryStore`. `test_detonate_without_clickhouse` and `test_cli_detonate` cover the CLI path. They do not fail while the ClickHouse path exists.
- **#17 v1 `content_hash` ignores a top-level `HASH` file.** Partial. `test_hash_file_changes_v2_digest` and `test_v2_hash_changes_with_bytes_path_or_execute_bit` pass for v2. `test_hash_file_does_not_change_digest` still passes for v1, and `pipeline.scan_skill` calls v1.
